# StockMarketInsights

StockMarketInsights is a comprehensive stock tracking utility designed for the modern investor. It leverages the latest Android technologies to provide a fluid, responsive user experience for monitoring market trends and managing personal portfolios.

## Key Features

- **Real-time Search** — Quickly find stocks across global markets.
- **Watchlist Management** — Organize and track specific stocks with custom watchlists.
- **Data Visualization** — Interactive stock performance charts powered by MPAndroidChart.
- **Offline Support** — Local data persistence using Room database for seamless access.
- **Modern UI** — A clean, dark-themed interface built entirely with Jetpack Compose.

## Built With

- **Language:** Kotlin + Coroutines
- **UI:** Jetpack Compose (Material 3)
- **Networking:** Retrofit + OkHttp
- **Database:** Room
- **Architecture:** MVVM (ViewModel, StateFlow)
- **Charts:** MPAndroidChart

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/anmoltrvd-01/StockMarketInsights.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle and let dependencies download.
4. Run the app on an emulator or physical device.
